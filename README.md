## 🧠 Research

### Multimodal Emotion Recognition

Currently working on research related to:

**"A Contrastive Learning Approach to Multimodal Emotion Recognition with Cross-Modal Attention"**

The work explores combining information from multiple modalities such as:

* 📝 Text
* 🎵 Audio
* 👁️ Visual information

The goal is to build a more effective model for understanding human emotions using **multimodal learning, cross-modal attention, and contrastive learning**.
